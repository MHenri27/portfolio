# Portfolio

My personal portfolio, live at https://mhenri.me

The front-end design idea started as a prototype made by AI. I designed it further and built the rest myself.

It is plain HTML, CSS and JavaScript with no framework, hosted on GitHub Pages.

- index.html: the page
- css/style.css: the styles
- js/: the scripts
- js/projects.js: all the project content

To change a project, edit js/projects.js and run `node build.js`. That puts the content into index.html so search engines can read it.

To run it locally, open index.html or use `python3 -m http.server`.
